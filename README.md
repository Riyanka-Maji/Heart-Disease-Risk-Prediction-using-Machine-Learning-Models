# Heart Disease Risk Prediction using Machine Learning Models
This project compares multiple machine learning models to predict the risk of heart disease based on patient data.
## Dataset Used :
UCI Heart Disease Dataset (Cleveland dataset), accessed via Kaggle:  
[Heart Disease Dataset](https://www.kaggle.com/datasets/redwankarimsony/heart-disease-data)

## Models Used :
- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
## Evaluation Metrics :
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC Curve

## Key Insights:
- SVM achieved the best overall performance based on F1-score and balanced metrics.
- Random Forest also performed well with high precision.

## Tools & Technologies:
- Python
- Pandas, NumPy, Scikit-learn
- Matplotlib

## Outcome:
The project demonstrates how different ML models perform on healthcare data and helps identify the most suitable model for prediction.
